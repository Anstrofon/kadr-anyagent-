# Kadr (Any-Agent Edition)

**ШІ-нативний відеоредактор із GPU-прискоренням — тепер із підтримкою будь-яких CLI-агентів (OpenCode, Claude та ін.), моушн-трекінгом, записом голосу з мікрофона, імпортом із YouTube та пошуком зображень.**

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL_3.0-blue.svg)](LICENSE)

> [!NOTE]
> **Про цей форк:**
> Оригінальний проект розроблений автором **Black Triangle** ([HelpFreedom/kadr](https://github.com/HelpFreedom/kadr)).
> Ця версія перероблена та розширена під власні потреби, насамперед щоб **прибрати жорстку прив'язку до платного Claude Code** і надати повну свободу вибору локальних або відкритих моделей (OpenCode, Ollama, DeepSeek тощо), а також додати ключові інструменти для щоденного швидкого монтажу. Середовище де будувався цей форк: Arch Linux, KDE plasma Waylland, NVIDIA & Intel.

![Демо Kadr](demo.gif)

Kadr — це потужний багатодоріжковий відеоредактор (Electron + React + TypeScript), побудований навколо ідеї: *ШІ-агент повинен монтувати відео поруч із вами, на тому ж таймлайні та тими самими інструментами.*

## 🚀 Що нового в цьому форку

### 🤖 1. Any-Agent: Підтримка будь-яких ШІ-агентів (за замовчуванням OpenCode)
- **Відмова від монополії Claude Code:** Тепер ви не зобов'язані платити за підписку Anthropic.
- **OpenCode за замовчуванням:** Інтегровано підтримку [OpenCode](https://github.com/anomaly/opencode) або будь-яких інших CLI-інструментів, що дозволяє підключати моделі OpenAI, DeepSeek, Google Gemini, Anthropic, а також локальні моделі через Ollama/vLLM.
- **Гнучке налаштування:** Поруч із кнопкою «AI» додано іконку налаштувань (⚙️), де можна обрати агент зі списку (OpenCode, Claude Code, Aider, Custom), вказати довільну команду запуску, аргументи та змінні середовища (`env`).
- **Повна сумісність із MCP:** Вбудований MCP-сервер Kadr автоматично підключається до запущеного агента, надаючи йому повний доступ до стану проекту, маніпуляцій кліпами, створення Remotion-фрагментів і знімків вікна перегляду.

### 🎯 2. Моушн-трекінг (Motion Tracking у стилі After Effects)
- **Точний трекінг об'єктів:** Реалізовано алгоритми оптичного потоку Lucas-Kanade та Template Matching на базі OpenCV (`scripts/track_motion.py`).
- **Зручний інтерфейс відстеження:** Інтерактивне вікно з можливістю обрати рамку об'єкта (feature box) та зону пошуку (search box), перехрестям і живим відображенням полілінії траєкторії прямо на відео.
- **Прив'язка до будь-якого кліпу:** Розрахована траєкторія автоматично конвертується у ключові кадри (позиція та масштаб) і прив'язується до цільового кліпу (текст, стікер, інше відео чи Remotion-фрагмент) в абсолютному або відносному режимі.
- Доступний у контекстному меню будь-якого відеокліпу (*«🎯 Трекінг руху...»*) та з редактора анімації.

### 📥 3. Завантаження відео з YouTube (VideoCutter)
- **Пошук та імпорт без сторонніх сайтів:** Вбудований діалог швидкого пошуку роликів на YouTube через `yt-dlp`.
- **Попереднє обрізання:** Можливість задати точні межі початку та кінця фрагмента перед завантаженням — завантажується лише необхідний шматок відео без витрати трафіку та дискового простору.
- **Миттєве додавання:** Обрізане відео автоматично конвертується та додається до медіа-корзини та на таймлайн проекту.

### 📷 4. Пошук та імпорт фотографій (Google Web & Pinterest)
- **Кнопка `[ 📷 Фото ]` у медіа-панелі:** Швидкий пошук та імпорт зображень високої роздільної здатності.
- **Спеціальні джерела та фільтри:**
  - 🌐 **Google / Web** — швидкий пошук високоякісних фотографій;
  - 📌 **Pinterest** — пошук арту, естетичних фотографій та пінів із прямим завантаженням оригіналів з `i.pinimg.com`;
  - 🖼 **Шпалери (4K)** — пошук контенту надвисокої чіткості;
  - ✨ **PNG з прозорим фоном** — швидкий пошук графічних елементів, логотипів і вирізок для накладання.
- **Швидкі теги та прев'ю:** Картки результатів з бейджами роздільної здатності, панель попереднього перегляду та імпорт в 1 клік у поточний проект.

### 🎙️ 5. Запис голосу з мікрофона (Voiceover)
- **Швидкий запис на таймлайн:** Кнопка мікрофона у панелі транспорту, гаряча клавіша `R` або кнопка `🎙` на будь-якій аудіодоріжці.
- **Живий індикатор гучності (VU Meter):** Динамічна кольорова шкала рівня вхідного сигналу для перевірки мікрофона перед та під час запису.
- **Синхронний запис поверх відео:** Можливість відтворювати таймлайн під час запису, щоб коментувати відеоряд у реальному часі.
- **Захист від луни:** Автоматичне тимчасове глушіння звуку проекту під час запису для запобігання зворотного зв'язку динаміків у мікрофон.
- **Бездоганна якість:** Запис зберігається у нестисненому PCM WAV (16-біт, 48 кГц) у папку проекту та автоматично розміщується на обраній чи вільній аудіодоріжці від початкової точки запису.

### ⚙️ 6. Покращена стабільність на Linux (Wayland / Dual-GPU)
- Виправлено падіння та конфлікти графічного стеку (GBM / EGL) на гібридній графіці (Intel iGPU + NVIDIA dGPU) під Wayland (KDE Plasma 6, GNOME).
- Розумне керування апаратним прискоренням: рендеринг інтерфейсу залишається стабільним, а важкі задачі (OpenCV, Whisper, CUDA) мають прямий доступ до обчислювальної потужності NVIDIA.

## 🎬 Основні можливості редактора (інформація, з основного репозиторію)

- 🎬 **Повноцінний багатодоріжковий монтаж** — відео-, аудіо- та текстові доріжки, тримінг, зациклення, фейди, зв'язані аудіо-відео кліпи, повна історія скасувань (Undo/Redo). Зміна швидкості від ×0.02 до ×100 за допомогою Ctrl-перетягування за будь-який край кліпу.
- 📥 **Медиа звідусіль** — перетягування файлів на доріжки, картинок із браузера (автоматичне завантаження за URL), вставка з буфера обміну (Ctrl+V) включно зі скопійованими зображеннями.
- ⚡ **GPU-композитинг (WebGL2)** — вікно попереднього перегляду працює на тому ж рушії, що й фінальний рендер: експорт піксель-у-піксель (WYSIWYG).
- 🔑 **Ключові кадри всюди** — позиція, масштаб, обертання, прозорість, гучність, маски; робочий процес в стилі After Effects.
- 🧊 **Справжнє 3D** — нахил і глибина кліпів, «політ камери» всією доріжкою, перспективно-коректні текстури.
- 🎭 **Маски** — анімовані кромки та до 8 фігур із розмиттям країв (прямокутник, еліпс, трикутник, інверсія).
- 🌫️ **Ефекти** — димне зовнішнє сяйво на основі шуму Billow, параметричне розмиття по Гаусу, збереження власних пресетів.
- ⏪ **Реверс кліпів** — реверсування відео та аудіо в один клік зі збереженням кешу.
- 🔀 **26 переходів** — 14 переходів накладання (стиль Vegas) та 12 динамічних торцевих переходів (whip pan, zoom blur, RGB-split, glitch).
- 🗣️ **Локальне розпізнавання мови** — Faster-Whisper (large-v3) із пословними таймкодами та захистом від галюцинацій.
- ✨ **Авто-субтитри** — швидка генерація стильних анімованих караоке-титрів із пословним підсвічуванням.
- 🌊 **Неонова хвиля** — аудіо-реактивна лінія за гучністю діапазону (аналог «Bake Sound» із Blender).
- 🥁 **Монтаж під музику (Бити)** — автоматичне знаходження бітів у треку (порт `beat_track` із librosa) та прив'язка сітки таймлайну.
- 🔊 **Вбудована бібліотека звуків** — понад 260 звукових ефектів (CC0) та музичних підкладок із прив'язкою за точкою удару (hit point).
- 🗣️ **Озвучення тексту** — підтримка генерації голосу через ElevenLabs із розбиттям довгих фраз та локальним детектором дефектів вимови.
- ⚛️ **Remotion-фрагменти** — створення програмованої моушн-графіки на React/TSX безпосередньо як кліпів на таймлайні з живим Hot Reload.
- 🧩 **Підтримка 3D-моделей** — імпорт STL, 3MF, STEP, OBJ, GLB із мініатюрами та вимірами у мм.
- 🪟 **Відео з альфа-каналом** — прозорі WebM, ProRes 4444 та HEVC коректно відображаються як у прев'ю, так і при фінальному експорті.
- 📤 **Експорт без компромісів** — кодування через FFmpeg x264 з чесним бітрейтом, 8-семпловим motion blur, змішуванням кадрів та лімітером на −1 dBFS.

## 🛠 Вимоги та залежності

| Компонент | Для чого | Примітка |
|---|---|---|
| **Node.js ≥ 20** | Основне середовище | Рекомендовано LTS версії |
| **FFmpeg + FFprobe** | Імпорт, аудіомікс, експорт | Повинні бути доступні у системному `PATH` |
| **Python ≥ 3.10** | Whisper, моушн-трекінг, ШІ-модулі | Створюється віртуальне оточення `.venv` |
| **yt-dlp** | Завантаження з YouTube | Встановлюється або системно, або через pip |
| **CLI ШІ-агент** | Робота з ШІ-асистентом | `opencode`, `claude` або будь-який інший сумісний агент |

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію та залежності Node.js:
```bash
git clone https://github.com/Anstrofon/kadr-anyagent-.git
cd kadr-anyagent-
npm install
```

### 2. Налаштування віртуального оточення Python:
Для роботи локального розпізнавання мови (Whisper) та моушн-трекінгу (OpenCV):
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --no-cache-dir -r python/requirements.txt
```

*(Опціонально для прискорення на відеокартах NVIDIA)*:
```bash
pip install --no-cache-dir -r python/requirements-cuda.txt
```

### 3. Запуск у режимі розробки:
```bash
npm run dev
```

Для створення релізного пакету:
```bash
npm run build
```

## 🤖 Як працює ШІ-інтеграція (MCP Інструменти)

Kadr запускає локальний міст через протокол MCP (Model Context Protocol), відкриваючи агенту понад 20 спеціалізованих інструментів:

| Інструмент | Призначення |
|---|---|
| `kadr_state` | Отримання повного живого стану проекту (доріжки, кліпи, шляхи, маркери) |
| `kadr_eval` | Виконання коду та маніпуляція таймлайном (зі збереженням в історії Undo/Redo) |
| `kadr_snapshot` | Скріншот поточного кадру (дозволяє агенту «бачити» результат монтажу) |
| `kadr_export` | Запуск фінального рендерингу обраного діапазону |
| `kadr_transcribe` | Транскрибування аудіо за допомогою локального Whisper |
| `kadr_fragment_create` | Створення нового Remotion-компонента як кліпу таймлайну |
| `kadr_beats` | Аналіз музичного ритму та сітки бітів |
| `kadr_sounds` / `kadr_sound_add` | Пошук та точна розстановка звукових ефектів |
| `kadr_voice_speak` | Генерація озвучення та додавання на доріжку |
